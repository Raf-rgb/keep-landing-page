# Keep Landing Page

Sitio oficial de Keep, una app Android local-first para guardar artículos y leerlos después.

## Estructura

- `index.html`: landing page
- `privacy.html`: política de privacidad
- `terms.html`: términos de uso
- `styles.css`: estilos
- `assets/screenshots/`: capturas de la aplicación

## GitHub Pages

En GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**.
Selecciona `main` y `/ (root)`, guarda y espera a que GitHub publique el sitio.

Antes del lanzamiento, reemplaza el enlace `#` del botón de Google Play en `index.html` por la URL pública de la ficha de Keep.
