Política de privacidad

Última actualización: 16 de septiembre de 2026

Esta Política de privacidad explica cómo Keep trata la información cuando utilizas la aplicación. Keep está diseñada como una aplicación de lectura posterior con almacenamiento local.

1. Información almacenada en el dispositivo

Cuando guardas contenido con Keep, la aplicación puede almacenar localmente en tu dispositivo el artículo extraído, imágenes asociadas, URL de origen, título, autor cuando esté disponible, etiquetas, subrayados, estado y progreso de lectura y preferencias de la aplicación. Esta información forma parte de tu biblioteca local.

2. Uso de Internet

Keep utiliza una conexión a Internet cuando proporcionas un enlace para guardar un artículo. La aplicación accede al sitio indicado para obtener el contenido necesario para crear la copia de lectura local. También puede abrir el artículo original cuando eliges esa opción.

3. Servidores y cuentas de Keep

Keep no requiere una cuenta de usuario y la versión descrita por esta política no utiliza un servicio propio de sincronización en la nube para almacenar tu biblioteca. Los artículos, subrayados, etiquetas y progreso de lectura no se cargan a servidores operados por Keep.

4. Contenido de terceros

Los artículos y demás contenidos accesibles mediante enlaces pertenecen a sus respectivos autores, editores o titulares de derechos. Keep funciona como una herramienta para que el usuario guarde contenido para lectura personal y no opera como un repositorio público de artículos guardados.

5. Eliminación de datos

Puedes eliminar artículos desde la aplicación. Debido a que la biblioteca se almacena localmente, desinstalar Keep o borrar los datos de la aplicación puede eliminar la biblioteca y las preferencias almacenadas en el dispositivo.

6. Servicios de terceros

La aplicación accede a los sitios web que el usuario decide guardar. Esos sitios pueden aplicar sus propias políticas de privacidad al recibir una solicitud desde tu dispositivo. Esta política no controla las prácticas de privacidad de sitios de terceros.

7. Cambios a esta política

Esta política puede actualizarse si cambian las funciones de Keep o la forma en que la aplicación trata información. La fecha de actualización se mostrará al inicio de esta página.

8. Contacto

Para preguntas relacionadas con privacidad o con Keep, escribe a rafernandez.dev@gmail.com.
